## Highlights

HCMUT-AILib is a local-first, zero-cost semantic search engine and research assistant for academic papers. You describe what you are looking for in plain English and it finds papers by meaning, not just by matching keywords. Everything runs on a normal laptop CPU, and your queries never leave your machine.

## Features

- **Semantic search** over 1,000 arXiv papers (cs.AI, cs.LG, cs.CL, cs.IR; 2021–2025; 50 per category per year), using `all-MiniLM-L6-v2` (384-d) embeddings of title + abstract, stored in an embedded ChromaDB index with cosine similarity.
- **Filters:** Top-K (1–20), publication-year range, arXiv categories, author.
- **Result cards:** normalised match score in [0, 1], category badges, expandable abstract, TF-IDF keywords, PDF and DOI links.
- **Find similar papers** for any result.
- **Citation export** in BibTeX, APA and IEEE.
- **About tab** explaining the method, the meaning of the score, the dataset, limitations, licences and the arXiv acknowledgement.
- **BM25 lexical baseline** (`src/lexical_baseline.py`) for A/B evaluation.
- **Data pipeline** (`src/ingest.py`) that respects the arXiv API rate limit (one request every 3 s) and produces normalised JSON (`docs/data_schema.md`).

## Installation

```bash
git clone https://github.com/HCMUT-Fus/hcmut-ailib.git && cd hcmut-ailib
pip install -r requirements.txt
streamlit run src/app.py
```

See `README.md` for building the index from scratch and re-running ingestion.

## Known limitations

- The embedding model is English-only, so Vietnamese queries perform poorly.
- The corpus is a 1,000-paper stratified sample; only titles and abstracts are indexed, with no full texts.
- The score is a similarity measure, not a probability of relevance.
- The first start downloads the model (~90 MB) and requires internet access once.

## Compliance

Metadata comes from arXiv under CC0 1.0. Papers remain under their authors' licences, and the app links to arXiv rather than redistributing full texts. Thank you to arXiv for use of its open access interoperability. This project is not affiliated with or endorsed by arXiv. See `reports/ethics_legal_audit.pdf`.
